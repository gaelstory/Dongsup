# Refactoring UI 검토: sem-tax (셈 세무회계)

**Step 0:** 정적 HTML + 순수 CSS(`style.css` 667줄) + GSAP, Tailwind 없음, 컴포넌트 라이브러리 없음. `:root`에 색 토큰 9개(`--paper --pine --rule --seal --gold --ink --ink-2 --paper-2 --band`)와 **장부 격자 토큰(`--row: 56px`, `--half: 28px`, `--cols`, `--cell`)** 이 있음. 글자 크기 토큰은 없음. 다크 모드 없음(장부지 단일 테마). 이 페이지는 "모든 줄높이는 28px의 배수, 글자는 괘선 위에 앉지 않는다"는 자체 규칙을 갖고 있으므로 그 규칙을 기준으로 봤다.

**검증:** 렌더 확인. `shoot.mjs` 1440/390 전 장면 + 자체 캡처 1280/375 전 장면.

**전체 인상**
- 싸 보이게 만드는 것: 데스크톱은 거의 흠이 없는데 폰에서 제목, 리드, 소개 글, 푸터가 좁은 `항목` 열(약 193px)에 갇혀 한 줄 12~14자로 꺾이고 오른쪽 열은 비어 있다. 지난 QA에서 폼과 FAQ는 풀었지만 글 묶음은 남았다.
- 글자 크기가 11~40px 사이 20종이다(18/19/20/21/22/23/24가 모두 쓰임). 격자가 엄격해서 눈에 덜 띄지만 금액, 소제목, 라벨의 급이 흐려진다.
- 이미 잘 된 점: 줄높이와 세로 간격이 28/56px 격자 하나에서 나온다(세 페이지 중 간격 시스템이 가장 좋다). 금액 오른쪽 정렬, 라벨은 작고 값은 큰 위계, 솔잎색 채움 버튼이 구역마다 하나, 이번 달 표시가 색+띠+배지+`D-5` 글자로 중복 전달, 작은 붉은 글자에 더 짙은 `#A3281B`를 따로 쓴 점.

## 토큰 정리

**글자 크기** (고정 20종 + 유동 4종 → 고정 7종 + 유동 4종)

| 새 토큰 | 값 | 흡수하는 현재 값 |
|---|---|---|
| `--fs-xs` | 12px | 11, 12 (달력 눈금, 슬라이더 끝값, 배지). 11px 눈금은 12로 |
| `--fs-sm` | 14px | 13, 14, 15 (표 머리, 메모, 주석, 내비, 서비스 설명, 푸터) |
| `--fs-md` | 16px (900px 이상 17px) | 16, 17, 18 (본문, 장부 항목, 입력 숫자, 달력 날짜) |
| `--fs-lg` | 20px | 19, 20, 21, 22 (서비스 이름, 달 이름, 대표 이름, 차액 라벨, 푸터 상호) |
| `--fs-xl` | 24px | 23, 24, 26 (장부 금액, 수수료, h3, 폰 차액) |
| `--fs-2xl` | 32px | 28, 30, 32, 36 (합계 금액, 차액, 폰 h2, 폰 h1) |
| `--fs-3xl` | 40px | 40 (h2) |
| 유지 | 유동 4종 | 히어로 `clamp(48px, 5.2vw, 74px)`, 폰 금액 `min(…vw)` 3종 |

금액은 24(행) / 32(합계) 두 급, 소제목은 20 한 급으로 정리되는 것이 핵심이다.

**간격/줄높이**: `--row`/`--half` 격자가 이미 시스템이다. 줄높이 선언 50개 중 36개가 `var(--half)` 또는 `var(--row)`, 나머지도 대부분 그 배수. 격자 밖은 `22px`, `20px`, `14px`, `16px`, `1.3` 몇 곳(눈금, 배지, 금액 내부)뿐이라 그대로 둬도 된다. 3번은 이 규칙이 폰에서 깨진 한 곳.

**굵기**: 5종 → 4종(8번).

**색**: 12번의 토큰 3개 추가. 글자색은 `--ink` / `--ink-2` / `--pine` 3색 + 의미색(`--seal`, `--seal-ink`)으로 규칙 안.

**그림자/반경**: 그림자는 슬라이더 손잡이 `0 2px 6px`와 열린 메뉴 `0 18px 30px -24px` 2개뿐, 모두 세로 방향. 나머지 `inset` 값은 테두리 대용. 반경은 2px로 통일(12번).

## 확인한 것

- `shoot.mjs` 결과(`studio/.shots/rui-sem-tax/sem-tax/`): 로드, 데스크톱 9장, 폰 13장, reduced-motion 1장 전부 열람.
- 자체 캡처 1280×800 10장, 375×812 13장(`studio/.shots/rui-sem-tax/w1280-375/`). 6번은 1280 캡처를 확대 잘라서 확인.
- CSS 값 집계와 렌더된 페이지의 계산 스타일(글자 크기/굵기/색별 글자 수, 문단 폭 em).
- 대비: `check_contrast.py` 15쌍. `--ink-2` 7.29(띠 위 6.64), `--pine` 11.01, 버튼 11.01, `#A3281B` 6.64, `--seal` 4.42(2번), 금박 3.58(비문자), 테두리류는 9번.
- 열두 법칙: 1차 행동(10번), 글자색(3색+의미색, 통과), 굵기(8번), 행 길이(1, 4번), 그룹 간격(5번), 시스템 값(7, 12번), 색 배경 위 회색 글자(없음), 빛 방향(통과), 색만으로 전달(없음: 달력 기한 점은 날짜 숫자와 병기, 계산기 막대는 금액과 병기).
