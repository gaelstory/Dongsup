**Step 0:** 순수 HTML + 손으로 쓴 CSS + GSAP(Tailwind 없음, 컴포넌트 라이브러리 없음). `:root`에 색 토큰 17개, 폰트 2개, 이징 3개, 반경 1개(`--r: 2px`), 거터 1개가 있다. **글자 크기, 행간, 간격, 그림자, 선 색 토큰은 없다**(파일 머리 주석에 척도를 적어 두었지만 값은 전부 리터럴). 단일 다크 테마(`color-scheme: dark`) + 상품/안내/퀵뷰만 흰 면(`color-scheme: light`). 규칙은 이 페이지의 토큰(`--hm --hy --ln --fr --fog --dim --em / --ink --stone --em-deep`)에 맞춰 적용했다.

**전체 인상**
- 이 묶음에서 규칙을 가장 잘 지킨 페이지다. 빌더가 스킬의 Workflow B를 따라 파일 머리에 내용 순위와 척도를 적고 시작했고, 실제로 지켜졌다: 구역마다 채움 버튼 하나(히어로 잔불 / 퀵뷰 먹 / 서랍 잔불), 다크 면 글자색 3단계(서리 백, 안개, `#7C838A`)와 흰 면 2단계(먹, 돌), 글자 대비 전 구간 통과, 대문자 라벨 전부 자간 있음, 색 이름은 항상 글자 병기, 빈 장바구니와 빈 찜 상태가 설계되어 있음, 그림자는 떠 있는 것(퀵뷰, 토스트, 검색 줄, 날아가는 축소본)에만.
- 깎이는 곳은 세 군데다. (1) 값이 토큰이 아니라 리터럴이라 13~17px 사이에 글자 크기 5개가 1px 간격으로 서 있고, 굵기가 5종(400/500/600/700/800)이다. (2) 흰색/검정에 투명도를 준 선과 버튼 테두리가 9종. (3) 입력칸과 사이즈 칩의 테두리가 흰 배경에서 1.37:1이라 "누를 수 있는 상자"가 잘 안 보인다.

정책 2의 순서(글자색·크기 → 반경·그림자 → 간격)대로. 전부 매핑이며 모양을 바꾸지 않는다.

**글자색(이미 체계적, 리터럴만 정리)**
- 다크 면 3단계: `--fr`(기본) / `--fog`(보조) / `--dim`(3차). 흰 면: `--ink` / `--stone`. 강조: `--em`(다크), `--em-deep`(흰 면).
- 리터럴 `#fff`(5곳: `.btn--ink`, `.cnt`, `.pcard__quick`, 선택 칩) → `--paper`. `#6B7178`(품절 칩, 4.93:1) → 새 토큰 `--stone-2: #6B7178`. `#B4BAC0`(품절 대각선) → `--line-field`. `#FF7F48`, `#2A2E33`(버튼 호버) → `--em-hi: #FF7F48`, `--ink-hi: var(--ln)`. `#202326`(절개 창 바탕) → `--hy`.

**글자 크기(10종 → 7단계 + 표시용)**
```
--fs-2xs: 11px   배지 숫자, 촬영 캡션(장식 전용)
--fs-xs:  12px   대문자 라틴 라벨, 표 머리, 색 표시, 추천, 쿠폰 코드
--fs-sm:  14px   캡션, 보조 문장, 서랍·퀵뷰 본문 (13 · 14 흡수)
--fs-md:  16px   본문, 버튼, 카드 이름, 입력 (15 · 16 흡수)
--fs-lg:  18px   가격, 도해 한글 이름, 안내 열 제목 (17 흡수)
--fs-xl:  20px   아코디언 제목, 주문 요약 제목
--fs-2xl: 24px   안내 h2, 퀵뷰 이름, 결제 금액, 모바일 메뉴 (24 · 26 흡수)
--fs-3xl: 28px   고객센터 번호
표시용(clamp 유지): 로고타입, h1, h2 3종, 큰 제품명
```
- 13 → 14로 올릴 때 주의: 히어로 띠 컨트롤 줄, 프로모 문구(모바일 두 줄 유지 확인), 푸터 사업자 정보(13 → 14, 줄 수 변화 확인). 브리프가 13px로 못 박은 곳(큰 글자 캡션, 칩 주석, 구매안전 안내)은 정책 1 "읽기 쉬움이 브리프보다 우선"에 따라 14로 올려도 된다.
- 15 → 16: 내비(브리프 15px), 도해 설명(15px, 최대 17em)이 한 줄씩 늘 수 있다. 도해 라벨이 무대 밖으로 밀리면 도해 설명만 14로 내린다.

**굵기**
`--w-reg: 400 / --w-mid-ko: 500 / --w-mid-lat: 600 / --w-bold: 700` + 표시용 800. 300 이하 없음(정책 1 충족).

**행간**
`--lh-none: 1 / --lh-tight: 1.25 / --lh-snug: 1.4 / --lh-body: 1.6` + 표시용 `.86`.

**반경(이미 일관됨)**
`0`(이미지, 칩, 카드) / `--r: 2px`(버튼, 입력, 룩북 카드, 토스트) / `50%`(스와치, 점, 눈금) / `10px`(모바일 시트 윗모서리). 리터럴 `9px`(배지 = 높이의 절반) → `999px`, `.qv__grip::before 2px` → `var(--r)`, 절개 창 `10%`는 그림의 일부라 유지. 변경 불필요.

**그림자**
`--sh-2 / --sh-3 / --sh-4`(10번). inset 테두리(`box-shadow: inset 0 0 0 1px …`)는 그림자가 아니라 선이므로 선 토큰으로.

**선**
다크: `--ln`(장식) / `--ln-strong: #575C62` / `--ln-ctl: var(--dim)`. 흰 면: `--st-lo`(장식) / `--line-field: #8E959C`(컨트롤).

**간격**
```
--sp-1: 4   --sp-2: 8   --sp-3: 12  --sp-4: 16  --sp-5: 20
--sp-6: 24  --sp-7: 32  --sp-8: 48  --sp-9: 64  --sp-10: 96
```
척도 밖 값 매핑: 2 → 4, 5 → 4, 6 → 8, 10 → 12, 14 → 16, 18 → 16, 56 → 48(`.menu__list a` 높이 56은 터치 높이라 유지), 72 → 64(푸터 아래 72는 배지 자리, 아코디언 줄 높이 72는 브리프 값이라 유지). 묶음 관계(카드: 점 줄 → 이름 2 → 설명 2 → 가격 8 → 리뷰 4)는 4 / 4 / 8 / 4로 옮겨도 "가격 앞이 가장 넓다"가 유지된다.
