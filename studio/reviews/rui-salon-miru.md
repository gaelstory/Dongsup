# Refactoring UI 검토: salon-miru (살롱 미루)

**Step 0:** 정적 HTML + 순수 CSS(`style.css` 559줄) + Canvas 2D + GSAP, Tailwind 없음, 컴포넌트 라이브러리 없음. `:root`에 색 토큰 13개(`--pearl --champagne --wine --chrome --olive --ink` + 파생 `--wine-deep --ink-soft --line --line-strong --champagne-deep --hair-root --hair-tip`), `--gutter`, `--header-h`. 글자 크기, 간격, 반경 토큰은 없음. 다크 모드 없음. 기준은 이 페이지의 진주/샴페인/와인 시스템과 브리프의 "가느다란 선"이다.

**검증:** 렌더 확인. `shoot.mjs` 1440/390 전 장면(`studio/.shots/rui-salon-miru/salon-miru/`) + 자체 캡처 1280/375 전 장면(`studio/.shots/rui-salon-miru/own/`의 `d1280-NN`, `m375-NN`) + 375px DPR 2 세 장(가는 글꼴 확인용). 대비는 `check_contrast.py`로 계산.

**전체 인상**
- 싸 보이게 만드는 것: 본문이 16/17/18/19px 네 크기로 섞여 있고(같은 급의 설명문이 구역마다 다른 크기), 제목용 글꼴도 24/25/26/28/32px가 따로 논다. 한눈에는 안 보이지만 "어딘가 안 맞는" 느낌의 원인이다.
- 와인색 채움 버튼 `디자이너 예약하기`가 첫 화면에 2개이고, 입력칸과 칩의 테두리가 1.9:1이라 폼이 흐릿하다. 푸터 글자는 반투명 흰색이다.
- 이미 잘 된 점: 그림자가 하나도 없고 깊이를 샴페인/진주 배경 교차와 가는 선으로만 낸다(§6.4 그대로). 가격표는 이름(제목 글꼴) + 점선 + 금액(굵게, tabular) + 설명(작게)으로 위계가 정확하다. 예약 단계는 색+윗줄+체크 아이콘, 마감 시간은 점선+취소선으로 색에만 기대지 않는다. 본문 폭 20~36em, 글자색은 잉크/잉크 소프트/와인 3종.

## 토큰 정리

**글자 크기** (고정 12종 + SVG 4종 → 6종, clamp 7종 → 3종)

| 토큰 | 값 | 흡수하는 현재 값 |
|---|---|---|
| `--fs-xs` | 14px | 13(칩 요일), 14(`Salon MIRU`), 15(작은 버튼) |
| `--fs-sm` | 16px | 16(라벨, 설명, 칩, 캡션 36곳) |
| `--fs-md` | 18px | 17(폰 body, 큰 버튼, `designer-spec`), 18(body, 탭, 금액, 약속 제목), 19(`.lead`, 데스크톱 `hero-sub`) |
| `--fs-lg` | 21px | 21(약도 글자). 지금 19인 `.lead`를 본문과 구분하려면 이 단으로 올린다 |
| `--fs-xl` | 26px | 24(단계 번호), 25(메뉴 이름), 26(모바일 메뉴), 28(로고, 패널 제목) |
| `--fs-2xl` | 32px | 32(디자이너 이름, 완료 제목), `book-legend` clamp(27~32), 34(약도 상호) |
| 제목 | clamp 3종 | 히어로(화면 높이 예외 2종 포함), h2, 푸터 로고 |

**줄높이** 14종(1 / 1.08 / 1.1 / 1.16 / 1.2 / 1.25 / 1.3 / 1.35 / 1.4 / 1.5 / 1.6 / 1.7 / 1.75 / 22px) → 4단: `1.1`(40px 이상 제목), `1.3`(26~32px 제목, 한 줄 라벨), `1.5`(16px 설명), `1.7`(본문). 크기가 클수록 줄높이가 줄어드는 방향은 이미 맞다(§4.5.2).

**간격** (34종 → 9단): `--s-1: 4px` … `--s-9: 96px`(4/8/12/16/24/32/48/64/96). 간격 토큰이 없어서 책의 기본 스케일로 대체했다. 매핑: 2/5/6/7→4 또는 8, 10→8 또는 12, 14→12 또는 16, 18/20/22→16 또는 24, 26/28→24, 36/40/44→32 또는 48, 56→48 또는 64, 72/80→64 또는 96.

**반경** 11종 → `--r-sm: 8px` / `--r-md: 14px` / 999px. **외곽선 굵기** → `--stroke-display: 0.5px`. **색** → 신규 토큰 6개(`--placeholder`, `--line-control`, `--error`, `--champagne-soft`, `--rose` + 푸터 구분선 `#774653`).
