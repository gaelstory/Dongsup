# Refactoring UI 검토: gyeol-clinic (결 피부과의원)

**Step 0:** 정적 HTML + 순수 CSS(`style.css` 851줄) + GSAP, Tailwind 없음, 컴포넌트 라이브러리 없음. `:root`에 색 토큰 11개(`--frost --glacier --deep --apricot --ink --white` + 파생 `--ink-soft --rule --edge --error --deep-hover`), 글자 토큰 3개(`--t-sm 15` / `--t-body 17` / `--t-lg 18→19`), `--radius 24→28`, `--pad`. 간격, 그림자 토큰은 없음. 다크 모드 없음(`color-scheme: light`). 기준은 이 페이지의 서리 블루 시스템이고, 책의 기본 팔레트나 Tailwind 값은 쓰지 않았다.

**검증:** 렌더 확인. `shoot.mjs` 1440/390 전 장면(`studio/.shots/rui-gyeol-clinic/gyeol-clinic/`) + 자체 캡처 1280/375 전 장면(`studio/.shots/rui-gyeol-clinic/own/`의 `d1280-NN`, `m375-NN`). 대비는 `check_contrast.py`로 계산.

**전체 인상**
- 싸 보이게 만드는 것: 폰 375px에서 진료 시간표가 모든 행에서 `오전 10시 ~ 오후 / 7시`로 꺾인다(390px에서는 멀쩡해서 지난 QA를 통과했다). 그리고 그림자가 컴포넌트마다 따로 쓰여 7종이고, 버튼에 카드급의 크고 흐린 그림자가 붙어 있다.
- 작은 글자가 13/14/15/16/17px로 1px씩 다섯 단이다. 라벨, 주석, 표 머리의 급이 눈으로 구분되지 않는다. 간격 값도 35종이다.
- 이미 잘 된 점: 글자색이 잉크/잉크 소프트/심해 3종으로 끝나고 전 쌍이 대비 통과(최저 5.17:1), 본문 폭이 20~36em 안, 구역마다 서리/흰 배경이 번갈아 깔리고, 오늘 요일이 색+띠+`오늘` 글자로 겹쳐 전달되며, 금액은 오른쪽 정렬에 tabular 숫자, 불릿과 모노그램이 전부 렌즈 원 모티프다. P0는 없다.

## 토큰 정리

**글자 크기** (고정 10종 → 5종, clamp 9종 → 5종)

| 토큰 | 값 | 흡수하는 현재 값 |
|---|---|---|
| `--t-xs` (신규) | 13px | 11(오류 배지 `!`), 13(`오늘` 표시, 약도 라벨) |
| `--t-sm` | 15px | 14(표 머리, 렌즈 라벨, 비교 태그, 도움말, 오류, 힌트 8곳), 15 |
| `--t-body` | 17px | 16(탭, 입력칸: iOS 확대 방지로 16 유지가 필요하면 입력칸만 예외), 17 |
| `--t-lg` | 19px | 18(768px 미만 `--t-lg`), 19 |
| `--t-xl` (신규) | 22px | 22(금액), 26(모바일 메뉴 항목) |
| 제목 | clamp 5종 유지 | 히어로, 원칙, h2, 소제목(`concern__title`과 `doctor__name`은 같은 clamp로 합침), 완료 제목 |

**간격** (35종 → 9단): `--s-1: 4px`, `--s-2: 8px`, `--s-3: 12px`, `--s-4: 16px`, `--s-5: 24px`, `--s-6: 32px`, `--s-7: 48px`, `--s-8: 64px`, `--s-9: 96px`. 이 페이지에는 간격 토큰이 없어서 책의 기본 스케일로 대체했다. 매핑: 5/6→4 또는 8, 10→8, 14→12 또는 16, 18/20/22→16 또는 24, 26/28/30→24, 34/36/40→32, 44/52/56→48, 72/84/88→64 또는 96. 구역 padding(`clamp(88px, 10vw, 150px)`)은 그대로.

**그림자** 7종 → `--shadow-1/2/3` (표 5번). **반경** → 999px / 50% / `--radius` / `--radius-sm: 14px`. **색** → 신규 토큰 3개(`--frost-2`, `--placeholder`, `--error-bg`).

## 확인한 것과 확인하지 못한 것

- 확인: 1440/1280/390/375 전 스크롤 장면, reduced-motion 1장. 본문 폭과 줄 수(계산된 스타일로 측정), 라벨 간격(측정), 표 1번 수정안(375/360px에 CSS 주입 후 캡처), 대비 19쌍(전부 통과: 잉크 소프트 7.34:1, placeholder 5.17:1, 오류 5.93:1, 컨트롤 테두리 3.23~3.46:1).
- 확인 못 함: 폼 오류 상태와 완료 화면, 열린 모바일 메뉴, 탭 2~4번 패널, 호버와 포커스 모습(코드로만 봄). 실제 기기의 글꼴 렌더링(캡처는 DPR 1, 소프트웨어 렌더). 5번 그림자 토큰의 새 값은 렌더로 비교하지 않았다.
