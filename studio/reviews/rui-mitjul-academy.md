# Refactoring UI 감사: 밑줄 국어논술학원 (`work/mitjul-academy/`)

**Step 0:** 순수 HTML + CSS(`style.css`) + GSAP, Tailwind 없음, 컴포넌트 라이브러리 없음, `:root`에 자체 토큰 있음(책상, 모눈지, 연필, 빨간펜 2종, 파란펜, 형광, `--muted`, 선 3종), 다크 모드 없음. 글자 크기·간격 토큰은 없음.
**검증:** 1440×900, 390×844(`shoot.mjs`), 1280×800, 375×812(직접 촬영)에서 렌더 확인. 줄 번호는 `work/mitjul-academy/style.css` 기준.

**전체 인상**
- 이미 잘 된 점: 답안지 한 장이라는 틀 안에서 위계가 선명하다(원고지 제목 → 빨간 버튼 → 섹션 제목 → 본문). 글자색은 연필, `--muted` 둘에 펜 색만 얹었고, 작은 빨간 글자에는 따로 어두운 `--red-ink`(6.0:1)를 쓴다. 손글씨는 전부 21px 이상 700이라 빨간펜 `#DE3327`도 큰 글자 기준(3:1)을 넘는다(모눈지 4.35, 책상 3.90).
- 싸 보이게 만드는 것: 크게 없다. 13px부터 24px까지 1px 간격으로 거의 모든 크기가 쓰이고, 빨간색 5종과 선 투명도 6종이 낱개 값으로 흩어져 있다.
- 읽기에서 걸리는 것: 1280에서 섹션 리드 문단이 40em(한 줄 43~47자)으로 권장 폭(20~35em)을 조금 넘는다.

## 확인한 것

- 열두 법칙 점검: 주 액션(#11만 해당, 폼 구간은 하나), 글자색 3종 이내 통과(연필, `--muted`, 주석용 펜 색), 굵기 400 미만 없음, 본문 폭(#1 외 통과: 히어로 리드 31em, 단계 열 15em은 서너 줄짜리 짧은 글), 그룹 간격 통과(라벨 → 입력 6px < 문항 사이 22px, 제목 → 본문 18px < 섹션 사이 120px 이상), 색 배경 위 회색 글자 없음(빨간 버튼은 흰 글자 5.65:1), 빛 방향 통과, 색만으로 전달 없음.
- 대비 계산: `--muted` on 모눈지 7.42, on 책상 6.65 / `--red-ink` on 모눈지 6.02 / `--blue` on 모눈지 6.40 / 연필 on 형광 11.87 / 흰색 on 버튼 `#C42B20` 5.65. 빨간 손글씨는 큰 글자 기준으로 통과(모눈지 4.35, 흰 카드 4.56, 책상 3.90).
- 휴대폰 스크린샷에서 여백 메모가 `약속은 지`처럼 잘려 보인 것은 타이핑 애니메이션 도중 촬영된 것이다. 4초 기다린 뒤 다시 확인하니 8개 메모 모두 끝까지 쓰여 있고 화면 안(좌 38px ~ 우 347px)에 들어온다.
