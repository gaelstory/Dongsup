## 토큰 정리

- **글자 크기(렌더 13종 → 8단계).** `--t-cap: .875rem`(14, 메타·라벨·주석) / `--t-ui: 1rem`(16, 버튼·내비·입력칸 전용, 입력칸은 iOS 확대 방지로 16px 유지) / `--t-body: 1.0625rem`(17) / `--t-lead: 1.375rem`(22: 히어로 보조 20→22, 로고·`space__notes strong`·푸터 워드 리터럴 흡수) / `--t-h3: 1.5rem`(24: 리터럴 `1.5rem` 3곳, 모바일 코스 이름 26→24) / `--t-figure: 2rem`(32: 가격 30·코스 캡션 32) / `--t-h2`(그대로) / 히어로 제목 clamp(그대로). 15px(`--t-small`)은 없앤다. 단계 번호 13px과 SVG 약도 글자는 그림 요소라 예외로 주석만 단다.
- **간격(px 21종 → 9단계).** `--sp-1: 4px, --sp-2: 8px, --sp-3: 12px, --sp-4: 16px, --sp-5: 24px, --sp-6: 32px, --sp-7: 48px, --sp-8: 64px, --sp-9: 96px` + 미세 조정용 2px. 옮기는 법: 6→4 또는 8, 10→8 또는 12, 14→12 또는 16, 18→16, 20·22→24(촘촘한 곳은 16), 26·28·30→24 또는 32, 40→32 또는 48, 56→48 또는 64, 88→96. 구역 위아래 여백의 clamp와 svh 값은 화면 높이에 맞춘 연출 값이라 그대로 둔다. 묶을 때 반드시 "바깥 > 안쪽"(§3.6)이 유지되는 쪽으로 올림/내림한다. 현재 코스 목록(이름↔설명 6, 항목↔항목 42), 전통주 목록, 오시는 길 표는 이 규칙을 지키고 있다.
- **행간 11종 → 4종, 상자 반경 3종 → 1종.** 표 6·7번.
- **색.** 글자색 토큰은 5개(달빛·한지 / `--dim` / `--faint` / 놋쇠)다. 달빛과 한지는 제목·본문으로 역할이 나뉜 한 단계로 보면 "밝음 / 보조 / 흐림 + 강조색" 3단계라 규칙 안이다. 토큰 밖 글자색 2개(`#6E6A62`, `#918B80`)만 표 3번대로 정리한다.
