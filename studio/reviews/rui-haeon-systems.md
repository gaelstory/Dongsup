검토일 2026-11-25 · 대상 `index.html`, `style.css` · 코드 수정 없음(진단만)

**Step 0:** 순수 HTML + 손으로 쓴 CSS + Three.js 히어로(Tailwind 없음, 컴포넌트 라이브러리 없음), `:root`에 색·글자 크기 토큰 있음(간격·테두리 농도·행간 토큰은 없음), 의도적인 단일 다크 테마(`color-scheme: dark`). 규칙은 이 페이지의 토큰(`--night`, `--cyan`, `--mist`, `--mist-2` 등)에 맞춰 적용했다.

**전체 인상**
- 위계는 분명하다. 구역마다 가장 큰 것이 하나씩이고(히어로 제목, 사례의 큰 숫자, 콘솔), 표와 사양 목록은 값이 밝고 라벨이 흐려서 훑어보기 좋다. 깊이는 그림자 대신 남색의 밝기 차이로 냈고, 상태 표시는 색 점 옆에 항상 글자가 붙어 있다.
- '싸 보이는' 쪽으로 끌어내리는 것은 작은 글자의 가는 획이다. 화면 글자 202개 중 101개가 굵기 300이고 그중 79개가 14~15px이라, 어두운 배경에서 대시보드와 목록이 흐릿하게 뜬다.

## 토큰 정리

- **글자색.** 무채색 5톤 → 4톤(백 / `--text-soft #DCE5FA` / `--mist #A9B8D9` 9.12:1 / `--mist-2 #8C9CC4` 6.63:1), 가능하면 3톤. 강조는 `--cyan`, `--warm` 두 토큰만(리터럴 `#8FD8FF`, `#FFDDB5` 제거).
- **실선.** 흰색 투명도 9종 → `--line-faint` .08 / `--line` .12 / `--line-2` .2 / `--line-field` .3.
- **글자 크기.** 렌더 13종 → 토큰 `--fs-2xs` 13 / `--fs-xs` 14(콘솔·캡션 전용) / `--fs-sm` 15 / `--fs-body` 17 / `--fs-h3` / 지표 28 / `--fs-h2` / 사례 숫자 / h1. 워드마크 19px과 입력칸 16px은 예외로 주석.
- **굵기.** Gothic A1 300/500/800에 400을 추가해 300은 17px 문단 전용으로. Sora는 400/600만 로드되어 있어 상속된 300이 400으로 대체 렌더되고 있다(문제 없음, 그대로 둠).
- **간격.** 32종 → 13단계(4 8 12 16 20 24 32 40 48 64 80 96 160). 지금도 묶음 규칙(§3.6)은 지켜지고 있다(라벨↔입력 8 < 필드↔필드 20, 솔루션 행 내부 < 행 간격). 값을 옮길 때 이 관계가 뒤집히지 않게 한다.
- **행간.** 1.7 일괄 → 1.55(작은 글자·좁은 단) / 1.7(17px 문단) 두 단계 + 제목용 기존 값.
- **반경.** 2, 4, 7, 12, 20, 999px. 체크박스 7px만 6px 또는 4px로 맞추면 된다.
