# Refactoring UI 진단: 온기 베이커리 (`work/ongi-bakery/`)

**Step 0:** 순수 HTML + CSS + JS(Canvas 2D), Tailwind 없음, 컴포넌트 라이브러리 없음. `:root` 토큰은 색 8개(`--butter --cherry --milk --cocoa --mint --crust --cherry-deep --butter-soft`), 폰트 2개, `--g --line --radius`, 이징 2개. 글자 크기, 간격, 그림자 토큰은 없음. 라이트 전용(`color-scheme: light`).
**검증:** 1440×900, 390×844(`shoot.mjs`)과 1280×800, 375×812(직접 촬영) 화면을 전부 보고 판단. 표의 "코드"는 화면으로 확인하지 못한 항목.

**전체 인상**
- 싸 보이게 만드는 것: 값이 시스템 밖에서 1px씩 흩어져 있다. 글자 크기 15~34px 사이에 13종(17·18·19·20·21·22가 다 쓰임), 스티커 그림자 높이 1~8px 8종, 간격 값 44종. 한 화면에서는 안 보이지만 섹션을 넘길 때 "비슷한데 조금씩 다른" 느낌이 쌓인다.
- 본문 서체(Gowun Dodum)는 400 한 굵기뿐인데 타임라인 빵 이름에 700을 걸어 가짜 굵기가 합성된다. 그리고 글자 색이 사실상 코코아 한 가지라 보조 문구(힌트, 눈금, 부가 설명)가 본문과 같은 세기로 읽힌다.
- 이미 잘 된 점: 섹션마다 주 행동이 하나뿐이고(히어로 체리 버튼, 나머지는 우유색 보조), 그룹 간격이 내부 간격보다 확실히 크다. 그림자는 전부 아래 방향 단색이라 스티커 컨셉과 "빛은 위에서" 규칙이 함께 지켜진다. 모든 글자·배경 쌍이 4.5:1 이상(최저 4.65:1). 문단 폭은 최대 28em. 빈 스탬프 카드(0 / 10) 상태도 설계돼 있다.

## 토큰 정리

| 종류 | 현재 | 제안 스케일 |
|---|---|---|
| 글자 크기 | 고정 13종 + clamp 6종 | `15 / 18 / 22 / 28 / 34` + 제목 clamp(히어로, h2, 이야기 제목, 푸터 로고) |
| 줄 간격 | 12종 | `1 / 1.12 / 1.3 / 1.5 / 1.7` |
| 간격 | 44종 | `4 8 12 16 24 32 40 48 64 72 96 120 152` |
| 스티커 그림자 | 8종 | `1 / 4 / 6 / 8px` (누름, 기본, 호버, 카드) |
| 반경 | 10종 | `6 / 12 / 24 / 999` |
| 글자 색 | 밝은 면 1색, 어두운 면 1색 + 투명도 1개 | 면마다 2단계: `--cocoa` + `--cocoa-soft #6B4428`, 코코아 면은 `--milk` + `#DED2C3` |
| 구분선 | 투명도 5종 | `--rule` 1종 |

`:root`에 `--fs-*`, `--sp-*`, `--lift-*`, `--rule`, `--cocoa-soft`를 선언하고 값만 치환하면 된다. 팔레트 6색과 24px 반경, 3px 외곽선은 브리프대로 유지.

## 확인한 것과 확인하지 못한 것

확인한 것
- 열두 법칙: 섹션당 주 행동 1개(통과), 글자 색 3개 이하(통과, 다만 단계가 없음 → 5번), 굵기(본문 400만, 1번의 합성 700 한 곳), 문단 폭 20~35em(통과, 최대 28em), 그룹 간격 > 내부 간격(통과), 시스템 값(2·3·4·7·8·9번), 색 배경 위 회색 글자(없음, 투명도 1곳 → 6번), 빛은 위에서(통과, 모든 그림자 x=0 y>0), 색만으로 전달(통과: 타임라인 상태는 문구 칩, 스탬프는 도장과 개수 표시).
- 대비(`check_contrast.py`): 우유/체리 4.65, 체리딥/우유 6.53, 체리/우유 4.65, 코코아/버터 10.20, 코코아/민트 10.51, 버터/코코아 10.20, 코코아/우유 13.43.
- 가로 넘침 없음(1440, 1280, 390, 375), 콘솔 오류 0.

확인하지 못한 것
- 호버·누름·포커스 상태, 스탬프 10칸 완성 화면, 모바일 메뉴 펼침 화면은 촬영하지 않았다(4번, 8번의 해당 줄은 코드 기준).
- 빵을 던진 뒤 문구 뒤에 빵이 멈추는 경우의 가독성은 이전 QA(`reviews/ongi-bakery.md` 1번)에서 다뤘고 이번에는 재현하지 않았다.
- 약도 SVG 라벨은 데스크톱에서 약 30px로 본문(18px)보다 크게 렌더된다. 모바일 가독성을 위해 이전 QA가 키운 값이라 결함으로 올리지 않았다. 손보려면 데스크톱에서 `.map` 폭을 480px 정도로 제한하는 방법이 있다.
- 360px 미만 폭은 이번에 보지 않았다.
