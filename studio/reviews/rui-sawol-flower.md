# Refactoring UI 진단: 꽃집 사월 (`work/sawol-flower/`)

**Step 0:** 순수 HTML + CSS + JS(Canvas 2D 꽃밭, SVG 꽃다발), Tailwind 없음, 컴포넌트 라이브러리 없음. `:root` 토큰은 색 11개(`--sky --stem --tulip --freesia --ranun --gyp --soil --soil-soft --sky-pale --sky-deep --tulip-press`), 선 3개, 폰트 2개, 그림자 3단계(`--shadow-sm/md/lg`), `--gutter --header-h`. 글자 크기, 간격, 반경 토큰은 없음. 라이트 전용(`color-scheme: light`).
**검증:** 1440×900, 390×844(`shoot.mjs`)과 1280×800, 375×812(직접 촬영) 화면을 전부 보고 판단. 표의 "코드"는 화면으로 확인하지 못한 항목.

**전체 인상**
- 싸 보이게 만드는 것: 세 페이지 중 가장 정돈돼 있지만 작은 값들이 반 픽셀 단위로 흩어져 있다. 글자 크기에 13.5 / 14.5 / 15.5px가 섞여 13~18px 구간만 9종이고, 모서리 반경이 12·14·16·18·20·22·26·28px로 여덟 가지다. 카드마다 둥글기가 미세하게 달라 "눈대중으로 맞춘" 인상이 남는다.
- 초록 작업대 패널 안의 보조 글자가 흰색 투명도 다섯 단계(.66 / .78 / .82 / .86 / .92)로 만들어져 있고, 그중 입력 placeholder는 대비가 기준선(약 4.4~4.5:1)에 걸린다.
- 이미 잘 된 점: 그림자가 3단계 토큰에서만 나오고 카드에 테두리와 그림자를 겹치지 않았다. 밝은 면의 글자 색은 흙 / 흙-연함 / 줄기(강조) 세 가지로 지켜진다. 굵기는 400/700 둘뿐. 섹션마다 분홍 버튼이 하나씩이고, 선택 상태는 색에 체크 표시나 라디오 점이 함께 붙는다. 꽃말 라벨은 값보다 약하게 처리돼 있다.

## 토큰 정리

| 종류 | 현재 | 제안 스케일 |
|---|---|---|
| 글자 크기 | 고정 18종(소수점 3종) + clamp 4종 | `14 / 16 / 18 / 22 / 28 / 40` + 제목 clamp |
| 줄 간격 | 9종 | `1 / 1.15 / 1.3 / 1.6 / 1.75` |
| 간격 | 44종 | `4 8 12 16 20 24 32 40 48 64 80 120` + 섹션 여백 clamp |
| 반경 | 12종 | `6 / 14 / 20 / 28 / 999` |
| 초록 면 글자 | 흰색 + 투명도 5종 | `#FFFFFF` + `--on-stem-2 #CFE0D6` |
| 초록 면 선 | 투명도 7종 | 2종 |
| 그림자 | 토큰 3종 + 직접 표기 2종 | 토큰 5종(`sm / md / lg / cta / cta-hover`) |

팔레트 7색과 서체 2종, 알약 모양 버튼, 3단계 그림자는 브리프와 현재 시스템 그대로 유지.

## 확인한 것과 확인하지 못한 것

확인한 것
- 열두 법칙: 섹션당 주 행동 1개(통과: 히어로, 작업대, 구독에 분홍 버튼 하나씩), 글자 색 3개 이하(밝은 면 통과, 초록 면 위반 → 3번), 굵기 400/700(통과), 문단 폭(통과, 최대 30em), 그룹 간격 > 내부 간격(통과), 시스템 값(4·5·7·8·9·10번), 색 배경 위 회색 글자(초록 면 투명도 → 3번. 하늘색 위 흙-연함은 5.15~5.45:1로 문제 없음), 빛은 위에서(통과), 색만으로 전달(통과: 꽃 선택은 체크 표시, 구독은 라디오 점, 이번 달은 `이번 달` 칩).
- 대비(`check_contrast.py`): 흙/튤립 4.59, 흙/튤립-누름 3.97(실패, 1번), 흙-연함/하늘 5.45, 흙-연함/흰색 6.58, 줄기/하늘 6.57, 프리지아/패널 6.32, 흰색/패널 10.07, placeholder/입력칸 4.42~4.53, `#CFC2B8`/흙 7.84.
- 가로 넘침 없음(1440, 1280, 390, 375), 콘솔 오류 0.

확인하지 못한 것
- 1번은 호버 화면을 촬영하지 않고 코드와 계산으로 판단했다.
- 꽃을 하나도 고르지 않은 작업대(`.bench.is-empty`), 주문·구독 완료 문구, 모바일 메뉴 펼침, 달력의 다른 달 선택 상태는 촬영하지 않았다.
- 작업대 패널 배경에는 격자 선이 겹쳐 있어 실제 대비는 계산값과 조금 다를 수 있다(패널 색은 `--stem`에 어두운 덮개 32%를 합성한 `#184B2F`로 계산).
- 360px 미만 폭은 이번에 보지 않았다.
