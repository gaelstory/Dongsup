서리재 시안 사진 교체 방법

1. 실제 촬영 사진을 이 폴더(./photos/)에 넣는다. 형식은 .jpg .jpeg .png .webp .avif만 읽는다.
2. main.js 맨 위 PHOTOS 설정에 './photos/파일이름.jpg' 처럼 ./photos/로 시작하는 경로만 적는다. 외부 주소, //, data:, .. 이 들어간 경로는 무시하고 코드 그림을 쓴다.
3. 파일 이름 규칙(권장): hero-1.jpg ~ hero-5.jpg / look-01.jpg ~ look-10.jpg / full.jpg / {상품 id}-{색}-front.jpg, {상품 id}-{색}-back.jpg (예: hanjum-hoody-ember-front.jpg)
4. 권장 크기: 히어로 띠 4:5 세로 1200x1500 / 룩북 3:4.4 세로 900x1320 / 전면 컷 16:9 이상 2560x1440 / 상품 4:5 세로 1200x1500, 밝은 회색 배경.
5. 슬롯 단위로 바뀐다. heroModels[2]만 채우면 3번 패널만 사진이고 나머지는 코드 그림이다. 객체로 쓰면 { src, alt, color, focal: '50% 30%' } 로 대체 글과 초점을 줄 수 있다.
6. 사진을 불러오지 못하면 그 자리만 자동으로 코드 그림으로 돌아간다. 비워 두면 ./photos/에 요청을 한 건도 보내지 않는다.
7. 기능 도해(소재 섹션)는 호출선 좌표가 그림에 묶여 있어 항상 코드 그림이다.
